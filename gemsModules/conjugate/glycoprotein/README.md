# GpBuilder Entity

The GpBuilder is a tool used to construct glycoproteins with GLYCAM-encoded glycans and a given protein in PDB format by identifying realistic attachment sites for the provided glycans.


## Services

Two services are currently provided, Evaluation and Build.

### Evaluate

Runs the GMML2 binary GpBuilderTable in order to generate an input file for the Build step.

### Build

Runs the GMML2 binary GpBuilder with the input file generated by Evaluation and finally produces a project zip for the user. A status.log is produced during the GpBuilder execution which a user can monitor.

## Usage

In v1, the user must always run an Evaluation manually first. Then they can send a Build request using the pUUID of the Evaluation.

Please see `$GEMSHOME/tests/022.test.GpBuilder.sh` for a minimal bash example of the current workflow.
